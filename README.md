TravelMate is a responsive travel discovery website that helps users explore popular tourist places in any city. Users can enter a city name and get nearby attractions with their name, category, address, image, and Google Maps location. The project uses the Geoapify Geocoding and Places APIs and Wikimedia Commons for location images.

Technologies Used:
HTML · CSS · JavaScript · REST APIs · Geoapify API · Wikimedia Commons API · Google Maps

Key Features:

🔎 Search tourist places by city
📍 Find attractions within a 15 km radius
🖼️ Dynamically fetch place images
🗺️ Open locations directly in Google Maps
📱 Responsive design for desktop, tablet, and mobile
⏳ Loading and error handling
🛡️ HTML input escaping for safer dynamic content
